# Expense Tracker - Django

Simple Django based expense tracker with monthly budgets.

## Features
- Add / Delete Expenses
- Category wise tracking (milk, food, etc.)
- Monthly Budget limit
- Django Admin Panel

## Tech Stack
Python, Django, HTML, CSS, SQLite

## How to Run Locally
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 8001
